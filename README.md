## 📖 نبذة عن المشروع

مشروع Facebook هو منصة تواصل اجتماعية حديثة وقوية تجمع بين التقنيات الأحدث والتصميم الاحترافي. يوفر المشروع تجربة مستخدم سلسة وآمنة مع مميزات متقدمة للتواصل والمشاركة والتفاعل.

---

## ✨ المميزات

### الأساسية
- ✅ **التسجيل والدخول الآمن** - نظام مصادقة قوي ومشفر
- ✅ **إنشاء المحتوى** - نشر الصور والفيديوهات والنصوص بسهولة
- ✅ **التفاعل الاجتماعي** - إعجابات وتعليقات وإعادة نشر
- ✅ **الرسائل الخاصة** - تواصل مباشر وآمن بين المستخدمين
- ✅ **الملفات الشخصية** - إنشاء ملف شخصي احترافي

### المتقدمة
- 🔔 **الإشعارات الفورية** - تنبيهات في الوقت الفعلي
- 🔍 **البحث المتقدم** - بحث عن المستخدمين والمحتوى
- 👥 **إدارة المتابعين** - متابعة المستخدمين الآخرين
- 🎨 **التخصيص** - تخصيص الملف الشخصي والإعدادات
- 🔒 **خصوصية قوية** - تحكم كامل على مستويات الخصوصية

---

## 🛠️ التكنولوجيا المستخدمة

### Frontend
- **React.js** - مكتبة واجهات المستخدم
- **Redux** - إدارة الحالة المركزية
- **Tailwind CSS** - التصميم والأنماط
- **Axios** - طلبات HTTP

### Backend
- **Node.js** - بيئة التشغيل
- **Express.js** - إطار العمل
- **MongoDB** - قاعدة البيانات
- **JWT** - المصادقة والأمان

### أدوات إضافية
- **Socket.io** - التواصل الفوري
- **Multer** - معالجة الملفات
- **Bcrypt** - تشفير كلمات المرور
- **Dotenv** - إدارة المتغيرات

---

## 📋 المتطلبات

قبل البدء، تأكد من وجود:
- **Node.js** (v14.0.0 أو أحدث)
- **npm** أو **yarn**
- **MongoDB** (محلي أو سحابي)
- **Git**

## 🚀 التثبيت

### 1. استنساخ المستودع
```bash
git clone https://github.com/Obadagamer/Facebook.git
cd Facebook
2. تثبيت المكتبات
Backend
bash
cd backend
npm install
Frontend
bash
cd ../frontend
npm install
3. إعداد المتغيرات البيئية
Backend (.env)
Code
PORT=5000
MONGODB_URI=mongodb://localhost:27017/facebook
JWT_SECRET=your_secret_key_here
NODE_ENV=development
Frontend (.env)
Code
REACT_APP_API_URL=http://localhost:5000
REACT_APP_API_TIMEOUT=10000
4. بدء قاعدة البيانات
bash
# تأكد من تشغيل MongoDB
mongod
5. تشغيل التطبيق
تشغيل Backend
bash
cd backend
npm start
تشغيل Frontend (في نافذة طرفية جديدة)
bash
cd frontend
npm start
التطبيق سيكون متاح على: http://localhost:3000
